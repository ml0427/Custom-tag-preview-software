# v0.145 項目詳情入口

- 路徑列只顯示上層路徑，目前資料夾名稱只保留在標題；項目數量只保留在摘要列。
- 封面與列表按鈕改為「詳情」，選取該項目並開啟資訊側欄，移除頁首的全域詳情按鈕。
- 保留封面／列表雙擊閱讀及右鍵閱讀；詳情按鈕阻止雙擊事件冒泡。六種配色不變。

驗證：32 個測試檔、158 項通過；包含詳情選取、精確路徑匯入、延遲完成與錯誤處理。typecheck、lint:css、前端 build、Tauri debug build 通過。修改前 GitNexus 影響分析為 Low，範圍為卡片／列表、圖庫與 App。

實際桌面測試使用獨立 QA 識別碼與資料庫、測試圖庫及兩頁 CTP 圖示 ZIP。確認列表與封面「詳情」均開啟正確項目的資訊側欄，未收錄 ZIP 可匯入，標題不再重複。使用者按 Escape 停止電腦操作，因此本次雙擊閱讀的桌面回歸未完成；既有事件連接與閱讀回歸測試通過。未操作正式圖庫資料。

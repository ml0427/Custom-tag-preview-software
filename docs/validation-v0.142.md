# v0.142 邏輯修正與驗證

日期：2026-09-12。基準：main 4446558。

## 修正範圍

- 路徑查詢統一斜線與大小寫，資料夾改名與刪除使用精確邊界，SQL LIKE 的 `%`、`_` 以字面值處理。
- 改名接受完整檔名，避免重複副檔名；資料夾名稱中的句點保留。資料庫失敗時嘗試復原檔案名稱。
- 檔案大小或修改時間改變時使舊指紋失效；重複檔使用完整 SHA-256，批次移除前再次驗證；保留最新以實際檔案修改時間判斷。
- 縮圖不再借用不同目錄的同名項目；快取核對來源路徑、大小、修改時間與封面設定。
- 規則預覽明列新增與移除標籤，與套用共用計畫；快照過期拒絕套用。項目、標籤與規則在同一交易提交，手動標籤保留。
- 重新命名、右鍵套規則與健檢共用有效規則解析，父目錄從資料庫逐層查詢。
- 圖庫避免舊請求覆蓋新狀態；名稱、標籤、備註搜尋及排序先於後端分頁；標籤資料批次載入。
- 目錄讀取或背景載入失敗公開錯誤，資料未完整前不判定遺失或未追蹤；健檢合併重複掃描目錄。
- 封面格子只掛載可視列與前後緩衝列，保留偶數欄、捲動與縮圖載入；列表縮小時修正超界位置。
- 資料庫 migration 以 user_version 管理，在交易前備份；失敗回滾。重掃保留 ID、備註、手動標籤與其他來源。
- build 增加應用、Node 與測試 TypeScript 檢查；移除 CLAUDE.md，維持 .workflow 停用。

## 驗證界線

沒有以正式資料庫或使用者檔案進行刪除測試。回收筒操作前的完整內容驗證已測試，但未實際批次刪除使用者資料。完整指紋需要讀完整檔案，耗時隨資料量增加。資料庫與檔案系統無共同交易，改名失敗會回報復原結果；批次移除中途失敗會明確提示未全部完成並重新整理。

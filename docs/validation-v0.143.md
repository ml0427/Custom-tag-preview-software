# v0.143 外觀整合與驗證

## 改動

- 將已確認的淺色／深色提案整合到正式 Vue/Tauri 介面，使用本機中文字型，不再載入 Google Fonts。
- 舊 parchment 設定遷移到 light；obsidian、forge、phosphor 遷移到 dark。初次使用預設 light，導覽列與設定頁都能切換並保存。
- 精簡導覽列、目錄標題、工具列與封面卡片；移除目錄綠點，保留來源路徑；詳情按鈕移到標題右側，面板預設寬度 300px。
- 初次使用預設封面檢視，保留既有列表／封面選擇。保留偶數欄、虛擬捲動、搜尋、排序、標籤與編輯功能。
- 封面 metadata 區固定 74px，同步更新 row pitch。列表縮圖 30×40px，含 padding 後符合 56px 虛擬列高；搜尋高亮使用適合兩種主題的語意色。
- 修正 800px 設定頁分類按鈕超出畫面的問題，三個分類均可直接操作。
- CTP 字標使用向量路徑，中央 t 為藍色；同步更新 favicon、ICO 與既有平台圖示。來源為 src-tauri/icons/ctp.svg，可用 `npx tauri icon src-tauri/icons/ctp.svg` 重建。
